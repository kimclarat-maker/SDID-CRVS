This repository contains the **official documentation for the SDID NIDA Enrollment system**. It provides guidance for both administrators and citizens on using the enrollment platform, including **biometric capture, self-verification, appointments, and center management**.

The documentation is structured for **easy navigation**, clear instructions, and multilingual support (English, French, Kinyarwanda).

## Overview

The SDID Enrollment Documentation provides step-by-step guidance to ensure **smooth, accurate, and secure enrollment of citizens**. It covers:

- Setting up the system
- Capturing and managing citizen biometrics
- Selfie verification
- Appointments scheduling
- Managing enrollment centers and devices
- Frequently asked questions

---

## Features

- Multilingual support: **English, French, Kinyarwanda**
- **Searchable documentation** with instant filtering
- **Mobile-friendly** and fully responsive
- Clear, human-readable instructions with **visual aids**
- Easy navigation through sections and subsections
- Step-by-step workflows for **administrators** and **citizens**

## Getting Started

1. Open `index.html` in any modern web browser.
2. Use the sidebar or search box to navigate to relevant topics.
3. Switch languages using the dropdown in the header.
4. Follow instructions in each section for accurate enrollment procedures.

## Documentation Sections

1. **Introduction** – Overview of the SDID Enrollment system.
2. **Installation** – How to set up the system and dependencies.
3. **Authentication** – Managing user accounts and secure login.
4. **Start Biometric Capture** – Step-by-step guidance for capturing citizen biometrics.
5. **Selfie Verification** – Instructions for facial verification and optional skips.
6. **Approving Requests** – Review and approve enrollment requests.
7. **Appointments Management** – Scheduling, modifying, and tracking appointments.
8. **Centers Management** – Manage enrollment centers, locations, and operating hours.
9. **Device Management** – Configure and maintain biometric devices.
10. **FAQs** – Common questions and answers for both citizens and administrators.
